# GitHub Upload Guide

From the project root:

```powershell
git add .
git commit -m "Finalize telco churn analysis project"
git push origin main
```

After pushing, verify that these folders are visible on GitHub:
- `data/`
- `notebooks/`
- `src/`
- `outputs/charts/`
- `outputs/tables/`

The repository README should render the executive dashboard automatically.
