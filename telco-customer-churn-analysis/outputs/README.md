# Analysis Outputs

This folder contains the reproducible outputs generated by `src/telco_customer_churn_analysis.py`.

## Visuals
- `executive_dashboard.png` — portfolio-ready executive summary.
- `charts/01_overall_churn_retention.png` — overall churn vs retention.
- `charts/02_churn_by_tenure.png` — lifecycle/tenure churn pattern.
- `charts/03_churn_by_contract.png` — contract-level churn.
- `charts/04_tenure_churn_boxplot.png` — tenure distribution by churn outcome.
- `charts/05_totalcharges_churn_boxplot.png` — historical total charges by churn outcome.
- `charts/06_logistic_churn_drivers.png` — logistic-regression associations.

## Tables
The `tables/` folder contains KPI, data-quality, statistical-test, model-performance, lifecycle, contract and risk-scoring results.

`customer_churn_risk_scores.csv` contains model-based scores for the available historical customer dataset. The model is evaluated out-of-sample before being refit on all available records for final scoring.
